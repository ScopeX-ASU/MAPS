## Documentation principles

MAPS documentation should explain externally observable behavior, scientific assumptions, interfaces, and safe extension points. Implementation details belong in code comments only when they are necessary to understand non-obvious logic.

The repository root remains the entry point for installation and high-level project usage. This directory is intended to become the durable technical knowledge base used by both developers and coding agents.
